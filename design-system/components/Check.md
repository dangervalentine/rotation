# Check

A square checkbox with an oxblood fill square when on, and a label.

**Consumer provides:** `label` and any checkbox attribute (`checked`, `onChange`, `title`…). Add `className="rt-check-sm"` for the small uppercase variant used as a Field `extra` ("Keep", "On"). In table cells with no visible label, use a bare `<input type="checkbox" className="rt-checkbox" aria-label=…>`.

- Labels say the state when checked: "I own this", "Show item names", "Keep".
