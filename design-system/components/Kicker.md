# Kicker

The small tracked uppercase label that sits above a title — category, day, section — exactly as a magazine runs one above a headline.

**Consumer provides:** `children` (one to three words) and `tone` (`"muted"` default, `"ink"` for the masthead, `"accent"` for one featured item per screen).

- Always above something; a kicker never stands alone as a heading.
- Write it in normal case in data; the style uppercases it so screen readers don't spell it out.
